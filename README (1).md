<h1>Hi, I'm Ivan 👋</h1>

**Backend & Data Integration Engineer** · Master of Information Systems, Telkom University

I build APIs that connect systems that were never designed to talk to each other. My master's thesis, **Flowbeat**, is a Laravel API adapter that unifies data from different medical devices into one canonical data model for remote patient monitoring. I also bring hands-on experience in project operations and HR, so I care about software that real people, not just developers, can use.

- 🔭 Currently building: tools for small businesses and personal productivity
- 🌱 Currently learning: Python for machine learning, Odoo development, AWS AI Practitioner
- 📍 Based in Bandung, Indonesia
- 🤝 Open to roles in backend engineering, system integration, data, and IT project coordination
